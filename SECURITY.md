# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 2.6.x   | ✅ |
| < 2.6   | ❌ (please upgrade) |

## Reporting a vulnerability

Please **do not** open a public issue for security problems (dupe keys, economy exploits, RCE via commands, etc.).

Prefer one of:

1. GitHub **Private vulnerability reporting** (Security tab), if enabled  
2. Contact the maintainer via the profile / Discord listed on the repository  

### Please include

- NovaCrates version
- Server software + version
- Description of the issue and impact
- Steps to reproduce (PoC)
- Whether the issue is already public

## What to expect

- Acknowledgement when possible
- Fix or mitigation in a reasonable timeframe for confirmed issues
- Credit in the changelog if you want it (optional)

## Safe harbor

We will not take legal action against good-faith research reported responsibly and without harming players or production economies.
