# Contributing to NovaCrates

Thanks for your interest in improving NovaCrates.

## Ways to contribute

- Bug reports
- Feature suggestions
- Pull requests (fixes, improvements, docs)
- Translations (`messages_*.yml`)

## Before you start

1. Search existing **Issues** and **PRs** to avoid duplicates.
2. For larger features, open an issue first and describe the idea.
3. Test on **Paper 1.20.6+** (Java 17).
